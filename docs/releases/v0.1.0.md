# mtevil v0.1.0

- Первый стабильный релиз для Linux x86_64 и IPv4. Можно запустить прокси на одном VPS или выделить отдельный вход с резервным выходом.
- После обновления прокси проверяет ответ Telegram. Если проверка трижды не проходит, он возвращается к предыдущей версии.
- Исправлены ложные оповещения при чередовании исправных выходов. На стенде все 30 внешних клиентов переподключились через резерв за 2,54 с.
- Установщик и `mtevilctl update` по умолчанию выбирают стабильные версии.
