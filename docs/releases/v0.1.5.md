- **Смена SNI без поломки старых ссылок (`mtevilctl sni`):** теперь прокси поддерживает список разрешённых доменов (`/var/lib/mtevil/allowed-sni.txt` в томе `state`). При смене домена через `mtevilctl sni <домен>` (или при перенастройке мастером) выдаётся новая ссылка, а все ранее выданные клиентские ссылки со старым `SNI` продолжают работать без перенастройки.
- **Удобное управление (`mtevilctl link`, `sni`, `user`, `setup`):** добавлены команды `mtevilctl link [--sni <домен>] [--user <имя>] [--all]`, `mtevilctl sni [домен]` (с быстрым выбором популярных TLS 1.3 доменов `1..4`), `mtevilctl user add/del/list` и `mtevilctl setup` для запуска мастера прямо из установленной папки, а также автоочистка старых `install.v*.sh`.
- **Пул резервных IP-адресов Telegram DC и быстрый фолбэк:** для основных и медиа-датацентров (`DC 2`, `DC -2`, `DC 4`, `DC -4`) добавлены альтернативные фронтенд-IP с ротацией медиа-потоков и мгновенным переключением на резервный IP при задержке подключения свыше `1.5 с`.
- **Буферизованный `TlsReader` на входящем трафике клиента:** чтение заголовка и тела FakeTLS-записей объединено в буферизованные чтения из сокета вместо 3 отдельных системных вызовов `read()` на каждую запись, что снижает задержки при отправке сообщений и загрузке медиа.
