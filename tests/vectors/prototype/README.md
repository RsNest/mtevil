# Synthetic prototype regression fixtures

These are independent Python-client expectations for Rust transport regression
tests, not captured Telegram traffic and not a complete accepted wire corpus.

`synthetic-ch.hex` uses public test key bytes 00..0f and timestamp 1700000000.
Tests adjust its timestamp XOR bytes before network use, preserving the HMAC.
`client-init.hex`, `client-payload.hex`, `client-reply.hex` were generated by
`faketls_client.py` with the same public test key. Payload is the ASCII text
`client marker through Direct`; response is `dc reply through Direct`.
They verify AES-CTR positions in both directions when init and payload share
a TLS record and the upstream response is split independently of TLS frames.
None contains account credentials or real Telegram message contents.
